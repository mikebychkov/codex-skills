# Java Review Reference

Check changed Java code for:

- compilation errors;
- incorrect method or constructor calls;
- missing methods or incompatible signatures;
- logical and functional defects;
- runtime exceptions;
- incorrect null handling;
- regressions;
- broken public or internal contracts;
- resource leaks;
- unsafe concurrency and thread-safety assumptions;
- changed behavior without adequate validation or tests.

Prefer concrete evidence from the changed execution path.
