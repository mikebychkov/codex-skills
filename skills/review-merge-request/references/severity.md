# Finding Severity

Use:

- P0 — catastrophic issue requiring immediate action;
- P1 — serious defect likely to break production, compilation, security, or a
  primary workflow;
- P2 — normal actionable defect that should be corrected;
- P3 — minor issue or low-risk maintainability problem.

Do not assign P0 or P1 without concrete evidence.

Severity must reflect demonstrated impact, not reviewer uncertainty.
